# 两项实用新型专利初稿交付说明

本次按 `2025204790597.pdf` 的“摘要—权利要求书—说明书—附图”体例，形成两项相互独立的实用新型初稿。为适应实用新型的保护客体，两个发明点均改写为具有明确实体部件、安装关系、电连接关系和可操作显示结构的装置，而不是把算法步骤单独作为方法权利要求。

## 附图生成与校验

两套专利各生成4张附图，共8张，源文件和导出的图片位于 `utility_figures/`。附图由 `fireworks-tech-graph` skill 的模板生成器生成，再执行几何校验、构图校验和 PNG 渲染；8张图的校验均通过。图中文字、图例和连接关系均为中文。修订版已将权利要求中的主要部件编号直接写入图中，并在两份说明书中增加“附图标号对照”表，便于逐项核对。

## 申请前复核重点

- 将申请人、设计人/发明人、地址、优先权和代理信息替换占位符；
- 对支架、接口、主机板、显示组件等实体结构补充实际产品尺寸、材料和安装方式；
- 对照现有公开文献检索新颖性和创造性，必要时收窄独立权利要求；
- 由专利代理师确认软件处理逻辑在本申请中仅作为装置的用途和控制功能出现，权利要求保护重点仍为装置的结构及连接关系；
- 确认第三方模型、数据集和权重的授权状态，以及申请日前是否已经公开。
